Your first run

From API docs to a clear result in four steps

No complicated setup and no repeating requests manually. Build the flow once, then run it whenever your API changes.

  1. 1
    Connect your APIEnter the Base URL, then add the tokens your authenticated requests need. Tenant headers are available when your API uses them.
  2. 2
    Bring in your endpointsImport Swagger/OpenAPI for a ready-to-test workspace, or load a JSON suite when you already know the complete flow.
  3. 3
    Run everything in orderClick Run all. Devman API waits for each response and reuses captured IDs, tokens, and other values in the following steps.
  4. 4
    Inspect, fix, and run againOpen any result to compare the expected status with the actual response, then adjust your API or test and rerun the flow.
✦

Everything stays together. Organize related endpoints into groups, search large suites, export your workspace, and save a Markdown report when the run is complete.
