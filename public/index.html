How to use Devman API

Just follow these four steps.

  1. 1
    ConnectAdd your base URL and token.
  2. 2
    Get the JSON fileIn Workspace, press “Download template,” then add your tokens and endpoints before saving the file.
  3. 3
    Import the JSON filePress “Import JSON / suite” and select your file, or drag it into the drop area.
  4. 4
    RunPress “Run all” and review the results.
