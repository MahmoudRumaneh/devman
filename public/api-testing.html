Devman API / API testing

Free browser-based API client

Free API testing tool — no install, no account

Devman API is a free, open-source REST API testing tool that runs entirely in your browser. Paste a route, drop in a Postman collection, import an OpenAPI or Swagger document, or paste a cURL command, then run it and inspect the response.

Start testing free

Test any request format

Devman API accepts whatever format you already have: an OpenAPI or Swagger document, a Postman collection export, a copied cURL command, or a plain endpoint line. You don't need to rebuild your requests from scratch.

GET /users
POST /users
PATCH /users/${USER_ID}

No install, no account

There's nothing to download and nothing to sign up for. Open devman-api.com and start adding requests. Your workspace, including pasted tokens, stays in your browser's local storage. If you'd rather keep everything on your own machine, run it locally with Node.js or deploy your own instance — see how it compares to Postman for the full self-hosting story.

Frequently asked questions

What is Devman API used for?

Devman API is used to build, run, and inspect REST API requests and multi-step workflows directly in the browser, without installing a desktop app.

Do I need to create an account to test APIs?

No. Devman API has no sign-up or login. Open the app and start testing; your workspace is saved in your browser's local storage.

Which request formats can I test with Devman API?

You can import OpenAPI 3.x and Swagger 2.0 documents, Postman Collection v2.0/v2.1 files, and cURL commands, or paste plain endpoint lines such as GET /users.

Does testing APIs with Devman API cost anything?

No. Devman API is free with no paid tier, and it is open source under the MIT license.

Can I test a private or local API with Devman API?

Yes. Run Devman API locally with Node.js to test localhost or private-network APIs directly from your machine, or set an allowlisted host on a self-hosted deployment.
