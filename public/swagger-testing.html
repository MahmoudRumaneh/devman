Frequently asked questions

What is Swagger 2.0 support in Devman API?

Devman API parses Swagger 2.0 (the OpenAPI predecessor format) JSON or YAML documents and converts each operation into a request-ready row, the same as it does for OpenAPI 3.x.

Can I import directly from a Swagger UI page URL?

Yes. Paste the URL of a page that embeds Swagger UI, and Devman API discovers the underlying spec document automatically instead of requiring the raw JSON/YAML URL.

Does Devman API work with Swagger UI pages that require login?

Not currently. The import fetches the Swagger UI page or spec document directly without credentials, so pages behind a login typically won't resolve. Download the spec file and import it directly instead.

What's the difference between Swagger 2.0 and OpenAPI 3.x support here?

Both are parsed by the same importer and produce the same kind of request-ready rows. Swagger 2.0 uses securityDefinitions where OpenAPI 3.x uses components.securitySchemes; Devman API normalizes both to the same token-variable mapping.

Can I refresh endpoints after the Swagger document changes?

Yes. Re-run the Swagger import and choose to replace the current endpoints or append only the new ones, skipping duplicate method/path pairs.
